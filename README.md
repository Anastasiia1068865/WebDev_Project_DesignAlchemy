# WebDev_Project_DesignAlchemy
Hairstyling Website!
The Website will be modern designed, it will include an easily readable text. It will be accessible for every person and will have a colourful design with a simple booking-system.
It will contain the useful information and advices from Nina Thompson for people, depending on their hair type and their problems, which they could find out straight on the Website.
The Website will have a button with all possible questions that people might have and the answers for them.
